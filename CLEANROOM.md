# How Pixelpress was made

Pixelpress is an independent, clean-room project. Its feature set was worked out from what any user can see of
batch image converters on the market: public store listings, release notes and reviews. No other app's code,
resources, strings or designs were opened, decompiled or copied. Every line here was written for this project.

The macOS app sits on Apple's ImageIO. The Windows app sits on Pillow, pi-heif and LibRaw (through rawpy).
